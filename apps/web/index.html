Requirements

every modern browser

Cloud lane

Works in any browser, right now. Firebase AI Logic sends prompts to gemini-3.5-flash-lite behind App Check. No setup, no extensions, no flags.

On-device lane

Needs Chrome 139+ on a desktop with Gemini Nano enabled (chrome://flags/#optimization-guide-on-device-model → Enabled). Without it the cloud lane runs alone and every screen says why the on-device lane is idle.

No Gemini Nano? A labelled reference run from the author's laptop fills every chart and rule. The app never pretends.

What was built

Spark plan · no server code
Five packages
tandem-guard, tandem-ai, tandem-bench, tandem-policy and tandem-router, each independently tested. Code
192 calibration runs
8 task types × 12 synthetic tasks × 2 lanes, scored by deterministic validators; 93 held-out tasks replayed for validation. Frontier
Wilson 95% intervals
Every rule carries a lower bound on pass rate, not a point estimate. Thresholds fixed before any data. Certificate
SHA-256 receipt chain
Every routing decision produces a receipt chained to the one before it. Tamper with one and the chain breaks. Verify
Live policy swap
The policy ships through Remote Config with onConfigUpdate; open apps change routes without a reload.

Questions from judges and developers

Do I need Gemini Nano to try it?

No. Every screen works without it, the on-device lane says why it is idle, and a labelled reference run from the author's laptop fills the charts.

Is anything simulated?

No. Every stamp shows the inferenceSource Firebase AI Logic reports, and every figure on this page comes from a result file in the repository.

What leaves my device?

Nothing for on-device answers. For cloud answers, the receipt shows the exact payload and the bytes sent. Receipts hold metadata only, never content.

How does a rule become local-first?

Four checks on the probe data: at least 8 tasks, a 95% lower bound of 75% on-device, within 5 points of the cloud, and a p95 answer time inside your latency budget.

Can I use the router in my own app?

Yes. The router is a TypeScript package over Firebase AI Logic: create it with your Firebase app and policy, call run with a task and input, and read the receipt.

Which Firebase products does it use?

AI Logic hybrid inference, App Check with reCAPTCHA v3, anonymous Authentication, Firestore and Remote Config, which ships the policy to open apps in real time.
